Explora GitHub Copilot durante el ciclo de vida del desarrollo de software con situaciones realistas, una aplicación completa y un backlog compartido. Trabajarás de forma iterativa para planificar cambios, crear código, probar el comportamiento, revisar solicitudes de incorporación de cambios y gestionar el trabajo con agentes.

## Situación

Eres desarrollador en Tailspin Toys, una empresa ficticia de financiación colectiva de juegos de mesa con una temática para desarrolladores. El backlog de tu equipo ya está registrado como incidencias de GitHub y puedes elegir una para empezar. Incluye trabajo de funcionalidades, como el filtrado y la paginación, y mejoras de calidad, como la accesibilidad y los estándares de programación.

## Elige tu entorno

GitHub Copilot te acompaña en el entorno en el que trabajas. Elige el que mejor se adapte a tu forma de desarrollar. Cada taller tiene su propia configuración y utiliza la misma situación de Tailspin Toys.

### [GitHub Copilot CLI (interfaz de línea de comandos)][cli]

Utiliza el asistente con agentes en el terminal. Trabaja con los modos Plan y Autopilot, instrucciones, aptitudes, agentes personalizados, el protocolo de contexto de modelo (MCP) de Playwright, Agent Merge y prácticos comandos de barra.

### [Aplicación GitHub Copilot][app]

Ejecuta sesiones de agentes en paralelo, cambia de modo de sesión, colabora en Canvas y gestiona incidencias y solicitudes de incorporación de cambios de GitHub desde la aplicación de escritorio.

### [Agente en la nube de GitHub Copilot][cloud]

Asigna incidencias de GitHub a un agente asíncrono, guía su trabajo, supervisa el progreso y revisa las solicitudes de incorporación de cambios que abre.

### [Visual Studio Code][vscode]

Utiliza GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo de agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
