**[GitHub Copilot CLI][about-copilot-cli]** を使うと、GitHub Copilot をエージェント型コーディングアシスタントとしてターミナルで利用できます。コードベースを調べ、コードを生成し、コマンドを実行し、外部ツールに接続できます。すべてコマンドラインから操作できるため、グラフィカルエディターに切り替えずに作業を続けられます。

このワークショップでは、Tailspin Toys を使った一連のワークフローを進めます。

1. GitHub Codespaces でプロジェクトを準備し、Copilot CLI をインストールして使い方を確認します。
2. 星評価に小さな変更を加え、ブラウザーでレビューして、最初のプルリクエスト (PR) を手動でマージします。
3. フィルタリングの Issue から始め、Plan モードで方針を決め、Autopilot モードで実装し、Interactive モードでレビューします。
4. リポジトリの指示を更新し、フィルタリングの作業に適用します。
5. 既存の `quality-checks` スキルをカスタマイズし、プロジェクトのチェックに使います。
6. Playwright のモデルコンテキストプロトコル (MCP) サーバーを追加し、ブラウザーでフィルタリングを確認します。
7. 品質保証 (QA) カスタムエージェントを作成し、要件、カバレッジ、検証の根拠をレビューします。
8. フィルタリングの変更全体をレビューし、フィルタリングの PR で Agent Merge を使います。
9. コンテキスト、モデル、共有、任意のクラウド委任に便利なスラッシュコマンドを確認します。

ワークショップでは、星評価の PR と、指示の更新、スキルの更新、QA プロファイル、テストを含むフィルタリングの PR の 2 つを作成します。フィルタリングと品質の作業では同じ会話とブランチを使うため、各ツールを試しながら作業を積み重ねられます。

## 前提条件

このワークショップに参加する前に、次を準備してください。

- [ ] **Copilot Student、Pro、Pro+、Business、Enterprise** のいずれかの有効なプランがある GitHub アカウント
- [ ] リポジトリと Codespace を作成する権限
- [ ] ターミナルまたはコマンドラインの基本的な知識

> [!TIP]
> 有料プランがありませんか。認証済みの学生は [GitHub Education][student-plan] を通じて GitHub Copilot を無料で利用できます。**Copilot Student** プランには、このワークショップで使うエージェント、MCP、コードレビュー、Copilot CLI の機能が含まれています。

> [!NOTE]
> Copilot Business または Copilot Enterprise を使用する場合は、管理者が Copilot CLI を有効にしていることを確認してください。
